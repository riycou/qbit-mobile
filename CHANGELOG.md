# Changelog

## v1.1.0

- Reworked the app source into a maintainable mobile/desktop PWA structure.
- Added Dashboard, Torrents, RSS, Advanced, Settings, Appearance, and Logs surfaces.
- Added Advanced qBittorrent preference controls with password/private-key fields filtered out.
- Expanded torrent actions for start/stop, force, recheck, reannounce, sequential, first/last piece priority, super seeding, rename, move, category, tags, delete, and file priority.
- Improved RSS all/unread/feed views, refresh flow, and add-from-RSS behavior.
- Added Windows installer tooling, Desktop/Start Menu shortcuts, uninstall script, and hidden autostart launcher.
- Added portable host `/health` endpoint and safer config loading.

## v1.0.0

- Initial public portable release.
